# ReFrameAI — Επίλεξέ το. Περιέγραψέ το. Ξαναφαντάσου το.

Στούντιο αφαίρεσης και αντικατάστασης αντικειμένων βίντεο με AI. Ανέβασε ένα
βίντεο, κλίκαρε οποιοδήποτε αντικείμενο, παρακολούθησέ το σε όλα τα καρέ και
αφαίρεσέ το, αντικατάστησέ το ή αναδιαμόρφωσέ το με γενετική AI.

> Το βίντεό σου. Το όραμά σου. Ξαναδημιουργημένο από AI.

## Τι είναι

- **Επιλογή με κλικ** — παύση σε οποιοδήποτε καρέ, κλικ στο αντικείμενο· το SAM 3.1 το τμηματοποιεί
- **Παρακολούθηση** — διάδοση μάσκας με optical flow (ή SAM video όταν έχει ρυθμιστεί)
- **Αφαίρεση** — inpainting βίντεο ανακατασκευάζει το φόντο, ο ήχος διατηρείται
- **Αντικατάσταση / Αναδιαμόρφωση** — το Muse Image δημιουργεί το βασικό καρέ, σύνθεση σε όλα τα καρέ
- **Βοηθός AI** — το Muse Spark μετατρέπει οδηγίες σε δομημένα πλάνα
- **Χρονολόγιο + σύγκριση** — αναζήτηση ακριβείας καρέ, προεπισκόπηση πριν/μετά

## Γρήγορη εκκίνηση

```bash
./start.sh            # τερματικό macOS/Linux
# ή διπλό κλικ στο start.command (Finder) / start.bat (Windows)
```

Ανοίγει το http://localhost:3000. Διακοπή με Ctrl+C.

Χωρίς διαπιστευτήρια AI η εφαρμογή τρέχει σε **τοπική λειτουργία προεπισκόπησης**:
μεταφόρτωση, αναπαραγωγή, επιλογή, παρακολούθηση, αφαίρεση και εξαγωγή
λειτουργούν· οι γενετικές επεξεργασίες χρειάζονται `MODEL_API_KEY`.

## Ρύθμιση

```bash
cp .env.example .env   # συμπλήρωσε APP_SECRET_KEY, MODEL_API_KEY, ...
```

| Μεταβλητή | Προεπιλογή | Σκοπός |
|---|---|---|
| `MODEL_API_KEY` | _(κενό)_ | Κλειδί Meta Model API (https://dev.meta.ai) |
| `DATABASE_URL` | `sqlite:///./data/reframe.db` | Ή Postgres σε παραγωγή |
| `MAX_UPLOAD_MB` / `MAX_DURATION_SEC` | 500 / 600 | Όρια μεταφόρτωσης |

## Χρήση

1. Εγγραφή → **Νέο έργο** → μεταφόρτωση MP4/MOV/WebM.
2. Παύση, **κλικ στο αντικείμενο** (εμφανίζεται η μάσκα).
3. **Παρακολούθηση αντικειμένου** για διάδοση της μάσκας.
4. Επίλεξε **Αφαίρεση / Αντικατάσταση / Αναδιαμόρφωση**, γράψε περιγραφή, **Δημιουργία**.
5. **Σύγκριση** αρχικού/αποτελέσματος, **Εξαγωγή** MP4.

## Ασφάλεια

- Μην κάνεις commit το `.env` — τα κλειδιά μένουν στις μεταβλητές περιβάλλοντος.
- Το `MODEL_API_KEY` δεν φεύγει ποτέ από τον backend.
- Άλλαξε το `APP_SECRET_KEY` σε παραγωγή.

## Περιορισμοί

- Η τοπική τμηματοποίηση είναι κατά προσέγγιση· το SAM cloud είναι ακριβές.
- Η αφαίρεση χρησιμοποιεί OpenCV inpainting (καλή για μικρά αντικείμενα).
- Μέγιστο 16 αντικείμενα ανά αίτημα SAM (όριο API).
